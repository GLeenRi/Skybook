# SkyBook EFB

Electronic Flight Bag application.

Features:
- Aircraft selection
- Airbus / Boeing / ATR / Embraer / Cessna checklists
- Flight phases checklist system
- Progress tracking
- Flet GUI

Aircraft included:
- Airbus A320neo
- Airbus A350-900
- Airbus A380-800
- Boeing 737-800
- Boeing 737 MAX 8
- Boeing 777-300ER
- Embraer E190-E2
- ATR 72-600
- Cessna C172 Skyhawk

Built with Python and Flet.
